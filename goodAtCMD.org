* cmd hacks
** cmd expansions
*** capture the last argument of the previous command
*!$*
#+begin_example
mkdir -p system/user
cd !$
#+end_example


*** likewise getting other arguments
=!*=   *-all args of previous command*
=!:1=  *-first argument of prev command*
=!!=   *-entire previous argument*

*** store the prev command in ref and use it
#+begin_src
dir="systemd/user"
mkdir -p "$dir"
cd "$dir"
#+end_src


*** shortcuts to expand at a point
=Alt+.= *-last argument of previous command*
=C-M-e= *-explicitly expand shell history expansions without executing*
=Alt+_= *-cycles through older arguments*xg

*** rm
rm uses glob pattern for expansion and it does not use regular expressions
**** common usecases
- delete all .txt files
  rm *.txt
- delete files staring with log
  rm log*
- delete files ending with digit
  rm *[0-9]
- delete files like file1 file2 but not file10
  rm file?
- delete files except .c files
  rm !(*.c)
**** extended globing
enable it using
shopt -s extglob

***** if you want regex use find command
find . -type f -regex '.*[0-9]\.log'
find . -type f -regex '.*[0-9]\.log' -delete

***** always preview before deleting
ls *.log
find . -regex 'pattern'

***** interactive delete
rm -i *.log
**** by creating an alias
alias rm='rm -i'
rm lesson*
***** you can check an alias using :- alias rm

*** find cmd
**** imp attributes
- limit the level of search
  -maxdepth <num>
- type of file search
  -type d (or) f
- if any permission requirements
  -perm 700
**** use cases
***** list all the dir that has perm 700(private-only user can access)
#+begin_src bash
  find . -maxdepth 1 -type d -perm 700
#+end_src
