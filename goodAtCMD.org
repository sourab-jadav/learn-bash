* cmd hacks
** cmd expansions
*** capture the last argument of the previous command
*!$*
#+begin_example
mkdir -p system/user
cd !$
#+end_example


*** likewise getting other arguments
=!*=   *-all args of previous command*
=!:1=  *-first argument of prev command*
=!!=   *-entire previous argument*

*** store the prev command in ref and use it
#+begin_src
dir="systemd/user"
mkdir -p "$dir"
cd "$dir"
#+end_src


*** shortcuts to expand at a point
=Alt+.= *-last argument of previous command*
=C-M-e= *-explicitly expand shell history expansions without executing*
=Alt+_= *-cycles through older arguments*xg

** using core-utils
*** ls command
ls -ld = displays current directory permissions
*** grep command
grep <grep-options> '<grep location>' <patternopts> '<pattern>'
**** flags
***** grep options
1. r - recurse through all subdirectories
2. n - show the line numbers
3. w - match the exact word
4. C - add lines above and below the match line
   grep -rnwC 2 '.' -e 'set'
5. -E - extended grep in pattern opts
   #+begin_src bash
     grep -rnw '.' -e 'set(' -e ': set'
     (or)
     grep -rnw '.' -E 'HashSet|TreeSet|Set<'
   #+end_src
***** pattern options
1. -e - the pattern to look for

*** managing processes
- vi &   -> this starts a background process
- watch -n 2 'ps -aux'

**** jobs
when a fg process goes background in suspended state it enters joblist
jobs       # List jobs
bg %1      # Resume job 1 in background
fg %1      # Bring job 1 to foreground
kill %1    # Send termination signal to job 1

**** pgrep command
For finding a particular application and its processes, use:
pgrep -a -x firefox-esr


**** top command
monitor system processes

**** pstree command
-p show pids
-s <pid> // show for specific process
-a //shows full command arguments
-h // highlights current process
$USER // shows process owned by the user
-c // will not compact identical processes

**** kill command
***** killing all processes related to a application
killall -9 emacs -- does not close gracefully and lead to loss of unsaved data
pkill -f emacs -- uses sigint and closes gracefully

*** rm
rm uses glob pattern for expansion and it does not use regular expressions
**** common usecases
- delete all .txt files
  rm *.txt
- delete files staring with log
  rm log*
- delete files ending with digit
  rm *[0-9]
- delete files like file1 file2 but not file10
  rm file?
- delete files except .c files
  rm !(*.c)
**** extended globing
enable it using
shopt -s extglob

***** if you want regex use find command
find . -type f -regex '.*[0-9]\.log'
find . -type f -regex '.*[0-9]\.log' -delete

***** always preview before deleting
ls *.log
find . -regex 'pattern'

***** interactive delete
rm -i *.log

**** by creating an alias
alias rm='rm -i'
rm lesson*
***** you can check an alias using :- alias rm
